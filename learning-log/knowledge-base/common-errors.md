# 常见错误汇总

记录开发过程中遇到的常见错误和解决方案。

---

## Java 版本相关

### 错误：无效的标记 --release
**现象**：Maven 编译失败，提示 "无效的标记: --release"

**原因**：Maven 使用的 Java 版本低于项目要求

**解决**：配置 Maven 使用正确的 Java 版本

---

## 依赖相关

### 错误：无法解析符号 lombok
**现象**：IDEA 显示红色错误，无法识别 Lombok 注解

**原因**：
1. Maven 依赖未下载
2. Lombok 插件未安装
3. 项目语言级别设置错误

**解决**：
1. 刷新 Maven 依赖
2. 安装 Lombok 插件
3. 设置项目语言级别为 Java 17
